# Modern Portfolio with Analytics Dashboard

A modern, responsive portfolio website with a real-time analytics dashboard.

## Features

### Portfolio
- Responsive design using Tailwind CSS
- Animated sections with AOS library
- Dynamic typing effects
- Interactive project showcases
- Contact form
- Smooth scrolling and animations

### Analytics Dashboard
- Real-time visitor tracking
- Page view statistics
- Session duration monitoring
- Bounce rate calculation
- Traffic source analysis
- Popular pages tracking
- Live activity feed

## Technologies Used
- HTML5
- Tailwind CSS
- JavaScript
- Chart.js
- ApexCharts
- AOS (Animate on Scroll)
- Typed.js

## Setup
1. Clone the repository
2. Open `index.html` for the portfolio
3. Open `dashboard.html` for the analytics dashboard

## Usage
- Portfolio: Visit `index.html` to view the portfolio website
- Dashboard: Access `dashboard.html` to view real-time analytics
- Both pages work together to provide live tracking and statistics
